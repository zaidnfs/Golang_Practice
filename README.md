# Golang Practice & Mini Projects 🚀

This repository contains all the Go (Golang) concepts I’ve practiced, from the basics to concurrency and file operations. It also includes a mini project that applies these concepts in a practical way.

## 📁 Folders Overview

- **01-Hello-World** to **04-Conditional-Stmt** – Basic syntax, data types, and functions
- **05-Loops** to **10-Pointer** – Arrays, slices, maps, structs, and pointers
- **11-Error** to **14-Goroutine** – Error handling, interfaces, and concurrency
- **15.1 to 16-Select-Stmt** – Advanced concurrency with channels, worker pools, and select statements
- **17-File-IO** – Reading from and writing to files
- **18-Mini-Project** – A website checker that reads URLs from a text file and logs their status

## 🛠️ Mini Project: Website Checker

**Files:**
- `mini-project.go`: Main program to check the status of websites
- `websites.txt`: List of websites to check
- `website_checker.Log`: Output log showing the status (up/down) of each website
